Network

The container always listens on 0.0.0.0:3825 internally — that's set by the Dockerfile and can't be changed from inside the app. Your public address is decided by the orchestrator:

  • Coolify / similar PaaS — set the domain in the Coolify resource; its reverse proxy handles TLS + routing.
  • Direct docker compose up — edit the ports: line in docker-compose.yml and redeploy.
  • Reverse proxy (Caddy / nginx / Traefik) — point it at the container's :3825.

Public base URL is what shows up in verification emails and OIDC redirect URIs — set it to whatever users type in the browser.

SSL cert pull

Pulls renewed TLS certs into /data/certs/ for your reverse proxy (Caddy / nginx / Traefik). Two modes — Webhook for plain JSON APIs, or Script for anything that needs custom auth, multiple headers, or non-JSON responses. Full setup guide →

Vitriol makes one HTTP request and parses JSON out of the response. Good fit for plain JSON cert APIs. Webhook field reference →

Limits

Fair Queue Burst Weights

How many jobs a role can burst into available slots per turn before the queue rotates to the next user. Only the ratio matters — Super Admin 5 / Admin 3 / User 1 means a super admin gets 5× the throughput of a regular user. Range 1–20.

Output-side caps. Stone-mode cross-format conversions can balloon a small input into a much larger output — these stop a 5 MB upload from turning into a 110 MB file that bypasses the upload cap. 0 = unlimited for both. Per-user and per-role overrides live on the Users + Custom Roles dialogs.

Output retention (per role)

How long converted output files stay in /data/outputs/ before being cleaned up. max files = 0 means unlimited count. max age = 0 means no time-based cleanup. Delete on download removes the file from disk right after the user successfully downloads it (regardless of age / count limits). Cleanup runs every 30 minutes.
