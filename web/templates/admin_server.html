Network

The container always listens on 0.0.0.0:3825 internally — that's set by the Dockerfile and can't be changed from inside the app. Your public address is decided by the orchestrator:

  • Coolify / similar PaaS — set the domain in the Coolify resource; its reverse proxy handles TLS + routing.
  • Direct docker compose up — edit the ports: line in docker-compose.yml and redeploy.
  • Reverse proxy (Caddy / nginx / Traefik) — point it at the container's :3825.

Public base URL is what shows up in verification emails and OIDC redirect URIs — set it to whatever users type in the browser. Allowed origin, if set, rejects any request whose Host header doesn't match — useful as a defense-in-depth layer behind a misconfigured proxy.

OpenID Connect (Authentik / Keycloak / Auth0 / Okta)

Generic OIDC. Paste your provider's issuer URL (with or without /.well-known/openid-configuration) — discovery handles the rest. Redirect URI: /api/v1/auth/sso/oidc/callback

Server secret key

Used to sign session tokens and encrypt SMTP / OAuth / SSL secrets at rest. Generated automatically on first run and persisted to /data/.secret_key. Rotating invalidates all sessions and re-encrypts stored secrets in place.

SSL cert pull webhook

Server calls this webhook (HMAC-SHA256 signed) to fetch fullchain.pem and privkey.pem; they're written to /data/certs/ for your reverse proxy.
